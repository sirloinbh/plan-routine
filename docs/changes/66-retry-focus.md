## 목적

"다시 시도" 버튼은 불러오기에 성공하면 사라져 포커스가 `body`로 빠졌다.

## 변경

`frontend/src/retry-button.tsx`(새 파일). 이슈는 세 화면을 적었지만 같은 버튼이 11곳에 있어, 공용 버튼 하나로 모두 바꿨다: 오늘 체크, 일기, 기간 체크리스트, 4주 안내, 기록, 달성률, 12주 목표, 프로젝트 목록.

버튼이 포커스를 가진 채 사라지면 포커스가 이름 있는 가장 가까운 영역으로 간다. 카드 안이면 그 카드, 아니면 페이지 제목으로 이름 붙은 페이지 영역이다. 이슈의 "제목으로"를 이렇게 일반화했다. 낭독기는 영역의 이름, 곧 제목을 읽는다. 사용자가 이미 다른 곳에 있으면 포커스를 옮기지 않는다.

## 테스트

`frontend/src/retry-button.test.tsx`: 영역으로 이동, 카드 우선, 다른 곳에 있을 때 그대로. `diary.test.tsx`: 실제 화면에서 다시 시도 뒤 포커스.
