## Behavior that changed

- `/` and unknown addresses now redirect to `/today` (#167).
- Backend errors use the standard `notFound` and `errorHandler`, so error logs carry `requestId`; some error texts changed ([record](../changes/145-standard-error-handler.md)).
- The editable date-range messages say "today and the 7 days before it" and "from 2000-01-01 on" (#157, #222).
- The diary does not reload in the background on purpose: its form is a working copy of the load, so a background refresh must not replace what the user typed ([record](../changes/178-diary-query.md)).

## Test and tooling notes

- The backend integration tests are per-feature files (`backend/test/db-*.integration.test.ts`, shared setup in `db-helpers.ts`) and run with `--test-concurrency=1` because they share one database (#158). They are skipped without `TEST_DATABASE_URL`; CI runs them.
- `scripts/gh-project.ps1` fails on macOS (it needs `USERPROFILE` and `~/.config/gh-personal`). The lanes used plain `gh` with `--repo sirloinbh/plan-routine` and the active account `sirloinbh`.
- One full `npm run check` at a time across lanes, guarded by a lock directory, because `node_modules` is shared.
